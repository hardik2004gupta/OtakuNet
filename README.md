# Anime Recommender MVP

Minimal scaffold for an anime recommender MVP.

Structure:
- `data/raw/` raw CSVs
- `data/processed/` merged CSV output
- `training/` preprocessing and training scripts
- `model/` trained artifacts (pickles)
- `app/` Flask app and static/templates

To run the app locally:

1. Install dependencies: `pip install -r requirements.txt`
2. Run: `python app/main.py`

This repo contains placeholder files. Replace pickles and implement training logic in `training/`.
